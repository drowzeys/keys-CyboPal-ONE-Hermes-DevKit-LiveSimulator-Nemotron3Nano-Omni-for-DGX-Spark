# Hermes briefing

Nemotron 3 Nano Omni is the eyes. This simulator is the body.

- Follow the operator with pan / tilt
- Pauli shows the one-word state
- The 27″ canvas takes markdown from any skill or tool call

Write a new JSON under `skills/examples/` and run:

```
./scripts/cybopal.sh skill skills/examples/your-skill.json
```
